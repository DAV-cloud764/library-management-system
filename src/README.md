# Student Library Management System - Backend

## Description

This is the backend of the Student Library Management System developed using Spring Boot.

## Technologies

- Java 21
- Spring Boot 3
- Spring Security
- JWT Authentication
- PostgreSQL
- Maven

## Features

- User Authentication
- Books Management
- Students Management
- Borrow and Return Books
- Dashboard Statistics
- REST API

## How to Run

1. Clone the repository.
2. Create a PostgreSQL database named `library_db`.
3. Update the database credentials in `application.properties`.
4. Run the application using:

```bash
mvn spring-boot:run
```

The server will start at:

```
http://localhost:8080
```
